# Tooling Preferences

- Uses Google ADK (`google.adk`) for all agent activities/orchestration rather than calling `google.genai` directly. Confidence: 0.95
- Uses Gemini's built-in Google Search Tool (`Tool(google_search=GoogleSearch())`) for web-research grounding. Confidence: 0.85
- Prefers a custom ADK `BaseAgent` for the imperative executor state machine, reserving `LlmAgent` for sub-agents, since `LlmAgent` owns its own generate→tool→respond loop. Confidence: 0.8
- Prefers FlaUI (UIA3) for the Windows-native control layer (can expose controls through a WebDriver-compatible service); explicitly avoids building a new agent around WinAppDriver (latest release 2020). Confidence: 0.9
- Prefers Windows-native automation APIs/tools for clicking and drag-and-drop over raw/physical mouse emulation — asks for tools "other than mouse click" (e.g., UIA patterns, SendInput-level synthetic input) because mouse clicks are inaccurate and fail on the PC. Confidence: 0.8
- Prefers Playwright/CDP for browser-page automation (including YouTube) rather than Windows mouse clicks for web-page controls whenever the DOM is accessible. Confidence: 0.85
- For the browser DOM layer, chose a direct CDP implementation (raw WebSocket to Chrome/Edge's DevTools Protocol via the `ws` package) over Playwright — auto-launching Chrome with `--remote-debugging-port=9222` if no endpoint is reachable, and exposing `browser_*` tools (navigate, find_element, set_value, click, press_key, list_elements, wait_for_selector). Confidence: 0.8
- Prefers high-level, site-agnostic browser tools that navigate straight to a search-results URL (e.g., a `browser_search` that goes to `youtube.com/results?search_query=…` or `google.com/search?q=…`) over typing into site-specific selectors + key-press timing, so one tool reliably searches Google/YouTube/Bing/Wikipedia without fragile per-site DOM. Confidence: 0.85
- For browser key presses, prefers dispatching real CDP `Input.dispatchKeyEvent` events over synthetic DOM `KeyboardEvent`s, since pages often ignore synthetic events for native handlers like Enter-to-search. Confidence: 0.8
- When a sub-agent needs vision (e.g., to analyze a screenshot), injects the screenshot as a user-message image part inside a custom ADK `BaseAgent` (the same pattern as the executor) rather than returning it from a tool — Gemini 2.5 flash rejects image parts inside `function_response`. Confidence: 0.8
- Leaf specialist agents that own Google Search (`GoogleSearchTool`) set `disallow_transfer_to_parent`/`disallow_transfer_to_peers` so ADK doesn't inject a transfer tool beside the search tool — Vertex AI rejects requests mixing search tools with other function tools. Confidence: 0.85
- Initializes the GenAI client (resolving `GOOGLE_APPLICATION_CREDENTIALS`/project/location to absolute values) before the ADK Runner builds its own internal `genai.Client()` from environment variables, so the ADK path uses resolved credentials. Confidence: 0.7
- Environment is Windows: uses the dedicated `powershell` tool for PowerShell syntax (e.g., `git diff ... | Select-Object -First 400`), not the cmd.exe `shell_command`, which rejects PowerShell pipelines. Confidence: 0.8
